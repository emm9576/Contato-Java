# Cadastro de Contatos

Este é um projeto de cadastro e consulta de contatos, desenvolvido em Java com integração a um banco de dados PostgreSQL.

## Tecnologias Utilizadas

- Java SE
- PostgreSQL
- JDBC (Java Database Connectivity)

## Pré-requisitos

- Java JDK instalado
- PostgreSQL instalado
- Driver JDBC do PostgreSQL adicionado ao projeto
